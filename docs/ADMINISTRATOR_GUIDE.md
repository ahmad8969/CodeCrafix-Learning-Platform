# Administrator Guide

## Capabilities

- User / teacher / course / batch management
- Enrollment operations
- Finance (admissions, fees, expenses, reports)
- CRM pipeline
- Helpdesk oversight
- Career / job / survey publishing
- Certificates & gamification settings
- Feature flags and institute branding (architecture ready)

## Recommended daily ops

1. Review open helpdesk tickets
2. Approve pending certificates
3. Check finance outstanding report
4. Monitor CRM follow-ups
5. Publish surveys / jobs as needed
